# pbdd-monitoring-dashboard
PBDD Intervention Monitoring and Reporting Dashboard
Department of Agrarian Reform
PBDD's intervention data is scattered across spreadsheets, paper forms and personal files, making monitoring, reporting and tracking beneficiary needs slow, repetitive and prone to errors. 
At-a-Glance Status View - Used by PBBD staff to quickly see the current status of monitoring activities.
Beneficiary and Organisation List - Used by PBBD staff to view beneficiary and organisation information.
Activity Record List - Used by PBBD staff to review recorded monitoring activities.
Report View - Used by PBBD staff to view and prepare monitoring reports.
